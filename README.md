# VpnBot

Telegram-бот для управления VPN-пользователями и подписками через Marzban.

Основная идея: у пользователя в чате одно UI-сообщение (панель), которое редактируется кнопками и событиями (напоминания, оплата, статус доступа).

---

## Что умеет бот

- Управление пользователями в Marzban: выдача/удаление/поиск.
- Проверка подписки и выдача конфигов.
- Напоминания об оплате за 2 дня, за 1 день и в день оплаты.
- Авто-ограничение доступа после просрочки оплаты.
- Поток оплаты через скриншот:
  - пользователь отправляет чек;
  - админу приходит карточка с кнопками подтверждения;
  - при подтверждении срок продлевается на месяц;
  - подписка в Marzban снова включается.
- Отчётность по подтверждённым оплатам за месяц.
- Нормализация дат оплат для миграции со старого формата.
- Каталог прокси: Telegram MTProto, Telegram WEB, SOCKS5 и HTTP/HTTPS для браузера.
- Добавление, изменение и удаление прокси администратором; записи сохраняются в SQLite после перезапуска.

## Команды

### Пользователь

- `/menu` — открыть меню новым сообщением в конце чата, даже если старая панель затерялась среди уведомлений.
- `/start` — открыть главный экран в конце чата.
- `/help` — показать справку.
- `/info` — инструкции для телефона/ПК/ТВ.
- `/subscribe` — данные подписки + `Оплачен до`.
- `/ping` — проверка доступности RU-сервера.
- `/proxies` — открыть список прокси и настройки подключения.

Основные кнопки панели:
- `🔑 Запросить ключ`
- `📋 Моя подписка`
- `💳 Оплата` (для платных тарифов)
- `📣 Объявления`
- `🌐 Прокси`
- `❓ Помощь` и `💬 Поддержка`

### Администратор

Прокси:
- `/addproxy <название> | <ссылка>` — добавить прокси; название может содержать пробелы.
- `/editproxy <ID> <название> | <ссылка>` — заменить название и настройки.
- `/deleteproxy <ID>` — удалить прокси.
- `/proxylist` — показать ID и подсказку по командам. Полный каталог доступен в `/proxies`.

Примеры (адреса и данные авторизации замените своими):

```text
/addproxy Telegram Европа | tg://proxy?server=proxy.example.com&port=443&secret=0123456789abcdef0123456789abcdef
/addproxy Telegram WEB | https://t.me/webproxy?server=webproxy.example.com&secret=0123456789abcdef0123456789abcdef
/addproxy SOCKS5 Европа | socks5://login:password@proxy.example.com:1080
/addproxy Web HTTP | http://login:password@proxy.example.com:8080
/addproxy Web HTTPS | https://proxy.example.com:8443
/editproxy 1 Telegram новый | https://t.me/proxy?server=proxy.example.com&port=443&secret=0123456789abcdef0123456789abcdef
/deleteproxy 1
```

Также поддерживаются `tg://webproxy?...`, `tg://socks?...`, `https://t.me/socks?...` и `socks5h://...`.
В адресах SOCKS5/HTTP/HTTPS порт обязателен; путь и дополнительные параметры не используются.
Спецсимволы в логине и пароле нужно кодировать для URL, например `@` как `%40` и `#` как `%23`.

Для Telegram в карточке есть кнопка подключения. Для HTTP/HTTPS показаны адрес, порт и данные авторизации для настроек браузера или системы. Прокси нужно получить и запустить отдельно: бот хранит каталог подключений, серверы прокси не создаёт.

Telegram WEB — отдельный тип прокси для Telegram. Его ссылка содержит `server` и `secret` без `port`: HTTPS и порт 443 фиксированы. Нужен клиент Telegram с поддержкой WEB-прокси. Кнопка в карточке использует `tg://webproxy`, поскольку [публичный сайт `t.me` пока не регистрирует `/webproxy`](https://github.com/telegramdesktop/tproxy-server/blob/master/ANDROID.md#proxy-links); исходная ссылка остаётся доступной для копирования.

Панель работает в личных чатах. Каталог доступен пользователям бота по тем же ограничениям оплаты, что и остальные разделы; при просрочке остаются оплата, статус подписки и помощь.

Любая команда, открывающая раздел панели, показывает его новым сообщением в конце чата. Кнопки внутри текущей панели редактируют то же сообщение. `/menu`, `/start`, постоянная кнопка «Показать панель» и кнопки в уведомлениях позволяют вернуть меню вниз. Старая панель удаляется; если удаление недоступно, её кнопки отключаются. Уведомления сохраняются. `/menu` доступна и при просроченной оплате и показывает меню оплаты. Бот при запуске регистрирует основные команды в меню Telegram.

На обычный текст и вложения, для которых нет действия, бот отвечает подсказкой с кнопками меню, помощи и поддержки. При ожидании чека объясняет, как отправить скриншот как фото; PDF и изображения, отправленные файлом, не принимаются. Ожидание чека сохраняется до получения фото. Администратору для текста, фото и опроса показывается подсказка о рассылке через ответ `/say`. Входящие сообщения сохраняются, чтобы их можно было отправить повторно или использовать для рассылки; подсказка появляется в новой панели в конце чата.

Пользователи:
- `/adduser <username>`
- `/deleteuser <username>`
- `/users [часть логина или маска]` — список по 8 пользователей. `/users fed` ищет `fed` в любой части логина, `/users f***` — логины на `f`. Регистр не учитывается; `*` заменяет любое количество символов.
- Кнопка `🚫 Заблокировать` в заявке пользователя.
- `/unblock <id>`
- `/blocked`
- `/activity`
- `/count`

Администратор также может открыть раздел «👥 Пользователи» на главной панели. В нём доступны вкладки «Все» и «Активные» (подключались за последние 5 минут), обновление, сброс поиска и карточки пользователей. Карточки открываются в том же сообщении; возврат сохраняет запрос и страницу. Команды `/users` и `/activity` после успешного отображения удаляются, чтобы не засорять чат. Поиск и страница сохраняются после перезапуска бота.

Подписки и платежи:
- `/setprice <username> <amount>`
- `/setdate <username> <YYYY-MM-DD>`
- `/setfree <username> <true|false>`
- `/compensation <days>`
- `/override <old YYYY-MM-DD> <new YYYY-MM-DD>`
- `/normalizepay` — привести даты оплаты к текущему `YYYY-MM` (с защитой от двойной оплаты).
- `/paystats [YYYY-MM]` — отчёт по подтверждённым оплатам (кнопка `✅ Подтвердить`).

Служебное:
- `/say` — рассылка объявлений (с push-уведомлением).
- `/logs` — меню: выбор файла и числа строк; `/logs 100` — сразу 100 строк; `/logs 200 2` — файл №2. В `.env`: `BOT_LOG_PATH` или `BOT_LOG_PATHS=file1.log,file2.log`.
- `/poll_result <id>` — общие результаты опубликованного опроса.
- `/poll_list` — панель опросов со страницами, результатами, обновлением и закрытием голосования с подтверждением.
- `/status` — серверная нагрузка.

Опросы: создайте в Telegram обычный анонимный опрос (один или несколько ответов) и ответьте на него `/say`. Бот создаст собственный общий опрос, сохранит его ID и перешлёт один и тот же опрос пользователям. Голоса всех получателей обновляют общие результаты; отзыв голоса тоже учитывается. Повторный `/say` на исходном опросе повторяет рассылку того же общего опроса. Отчёт показывает число успешных доставок и ошибок. Проценты считаются от числа участников, поэтому при нескольких ответах сумма может превышать 100%. Викторины, неанонимные и закрытые опросы получают понятный отказ. Исходные пользовательские опросы больше не засоряют список; старые записи сохранены, но общую статистику ранее разосланных независимых копий восстановить нельзя. Таблица опросов обновляется автоматически без удаления записей.

## Оплата и биллинг (текущая логика)

- Дата оплаты хранится как полная дата (`payment_date`).
- Напоминания отправляются **отдельным сообщением** с push (не правкой панели) по календарным дням:
  - `-2 дня`, `-1 день`, `0 день`.
- Внизу чата: «Проверить подписку» и «Показать панель»; в уведомлениях — кнопка «Показать панель».
- Если дата оплаты прошла — доступ в боте ограничивается до оплаты.
- При просрочке подписка в Marzban переводится в `disabled`.
- Биллинг проверяется при запуске и каждые 15 минут. Временные ошибки Marzban повторяются при следующей проверке; дневной отчёт администратору отправляется в 18:20 по времени сервера.
- При переносе даты оплаты или переводе на бесплатный тариф бот восстанавливает ранее отозванный доступ в Marzban; при временном сбое повторяет попытку автоматически.
- При подтверждении оплаты админом:
  - срок сдвигается на 1 месяц от текущей даты или конца оплаченного срока, если он ещё не истёк;
  - статус в Marzban возвращается в `active`;
  - событие попадает в журнал отчётности;
  - повторное подтверждение того же сообщения с чеком не продлевает срок второй раз;
  - при сбое Marzban подтверждение можно повторить, дата и журнал оплаты не меняются до успешной активации.

## Установка и запуск

1. Клонировать репозиторий:
```bash
git clone git@github.com:Kovshik387/vpnbot.git
cd vpnbot
```

2. Установить зависимости:
```bash
go mod tidy
```

3. Настроить `.env`.

Переменные также можно передать через окружение процесса — `.env` в этом случае необязателен. Каталог `data` и таблицы базы создаются автоматически; существующие записи сохраняются.

4. Запустить:
```bash
go run ./cmd/api
```

### Пример `.env`

```env
BOT_TOKEN=string
ADMIN_ID=int64
USERNAME_API=string
PASSWORD_API=string
MARZBAN_URL=http://127.0.0.1:8000
RUSSIAN_URL=http://127.0.0.1:8000
```
